We kept lighting the same building twice.

Cast started inside an architecture practice, where lighting was always the last thing modeled and the first thing to go wrong on site. We would build a room, submit it, and only see how the light actually behaved once the drywall was already up.

So we built the tool we needed: one model that shows daylight and fixtures together, early enough to change the design instead of apologizing for it. Cast is now used by studios who would rather test a hundred versions of a room on screen than live with one mistake in concrete.
